# Flashcards (iOS)

A small, fast, offline-first flashcard app for personal use. SwiftUI + SwiftData, Leitner spaced repetition, JSON backup that works with iCloud Drive / Google Drive / Dropbox via the Files app.

## Features

**Decks & cards**
- Decks and cards with full search
- Quick-add editor with "Save & add another" for rapid entry
- **Bulk import** from pasted text or .csv / .tsv / .txt — pick a delimiter, preview, import dozens at once

**Practice modes**
- **Flashcards** — tap to flip, swipe right = correct, swipe left = wrong
- **Multiple choice** — front + 4 options, distractors pulled from the deck
- **Written review** — type the answer, fuzzy match (Levenshtein) recognises typos
- **Match pairs** — 6 fronts vs 6 shuffled backs, track time and mistakes

**Smart scheduling**
- Leitner box system (5 boxes, 1 / 2 / 4 / 7 / 14-day intervals)
- **Mistake-priority queue** — struggling cards (more wrongs than rights) bubble to the top in every mode
- **Stale-card resurfacing** — cards you haven't seen in 14+ days show up in stats
- **Daily reminder** — local notification at your chosen time, no servers

**Stats dashboard**
- Per-deck Leitner distribution bars
- Top 5 most-missed cards
- Top 5 cards you haven't seen in a while

**Backup & restore**
- One-tap JSON export through the Files share sheet
- Works with iCloud Drive, Google Drive, Dropbox, OneDrive (whatever's installed)
- Restore as **merge** (upsert by ID) or **replace** (wipe + import)

100% local. No accounts. No network. No ads. No IAP. No telemetry.

## Build & run (you need a Mac with Xcode 15+)

You can't compile iOS apps from Linux. On a Mac:

1. Open Xcode → **File ▸ New ▸ Project ▸ iOS ▸ App**.
2. Settings:
   - Product Name: `Flashcards`
   - Interface: **SwiftUI**
   - Language: **Swift**
   - Storage: **SwiftData**
   - Minimum deployment: **iOS 17.0**
3. Delete the autogenerated `ContentView.swift` and the autogenerated `*App.swift`.
4. In Finder, drag everything inside `Sources/` into the Xcode project navigator.
   - Tick **Copy items if needed**.
   - Tick **Create groups**.
   - Add to target: your new app target.
5. In **Project ▸ Target ▸ Info**, replace the bundle Info.plist contents with `Sources/Resources/Info.plist` (or merge — keep your generated `CFBundleIdentifier`).
6. Pick your iPhone as the run destination, sign in with your Apple ID under
   **Project ▸ Signing & Capabilities ▸ Team**, then press ▶ Run.

### Sideloading without a paid developer account

Free Apple ID works — but the app expires every 7 days and you must re-run from Xcode (or use [AltStore](https://altstore.io) which auto-refreshes over Wi-Fi). A paid Apple Developer account ($99/yr) lets you keep it installed for a full year.

## Backup & restore

Backups are a single JSON file containing every deck and every card with full review state.

**Export** — Settings → *Export backup*. iOS opens the share/save sheet. Pick:
- **iCloud Drive** → file syncs to all your devices automatically.
- **Google Drive** → install the Drive iOS app and enable it under *Files ▸ Locations ▸ Edit*; it then appears here.
- **Dropbox / OneDrive / etc.** → same as Drive — install the app, enable in Files.

**Restore** — Settings → *Import backup*. Pick the JSON, then choose:
- **Merge** — adds new decks/cards; updates existing ones (matched by ID). Keeps things you've added on this device.
- **Replace** — wipes the library, then imports the backup.

The format is human-readable JSON, so you can open it in any text editor and tweak it manually if needed.

```json
{
  "version": 1,
  "exportedAt": "2026-05-01T10:30:00Z",
  "decks": [
    {
      "id": "…",
      "name": "Spanish verbs",
      "colorHex": "#4F8EF7",
      "cards": [
        { "id": "…", "front": "hablar", "back": "to speak", "box": 2, "nextReview": "…" }
      ]
    }
  ]
}
```

## Bulk import format

Open a deck → menu → **Bulk import**. Paste lines, or pick a file. Each line is one card with the chosen delimiter:

```text
# This line is ignored.
hablar	to speak
correr	to run
"vivir, sobrevivir"	"to live, to survive"
```

Defaults: TAB delimiter (paste straight from Excel, Numbers, or Sheets). Switch to comma for `.csv`, pipe `|`, or `::`. Empty lines and lines starting with `#` are skipped. Wrapping double quotes are stripped (`""` becomes a literal `"`). Anything past the second column is appended to the back, so `front,part1,part2` becomes `front` → `part1 part2`.

## Daily reminder

Settings → toggle **Daily reminder** → pick a time → done. iOS prompts for notification permission the first time. The app schedules one repeating local notification at that time and cancels it if you turn the toggle off. There's no server, no push token, no battery hit.

If you blocked notifications at the system level the toggle will tell you to fix it in iOS Settings → Flashcards → Notifications.

## How the Leitner system works

Every card lives in a box (1–5). After answering:

- **Correct** → move up one box. Next review in 1 / 2 / 4 / 7 / 14 days for boxes 1 / 2 / 3 / 4 / 5.
- **Wrong** → drop straight back to box 1, review again tomorrow.

The Study button shows the count of cards whose `nextReview` is in the past. If nothing is due, it studies the whole deck in random order (so you can practise any time).
